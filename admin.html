🔑 ایک بار سیٹ اپ کریں

یہ صرف پہلی بار کرنا ہے۔ آپ کا ٹوکن صرف اسی فون کے براؤزر میں محفوظ رہے گا، کہیں اور نہیں جاتا۔

ٹوکن بنانے کا طریقہ:
1) github.com پر لاگ اِن کریں
2) اوپر دائیں پروفائل تصویر → Settings
3) سب سے نیچے بائیں Developer settings
4) Personal access tokens → Fine-grained tokens → Generate new token
5) نام کچھ بھی دیں، Repository access میں "Only select repositories" چن کر صرف sj-foods منتخب کریں
6) Permissions → Contents → Read and write کریں
7) Generate token دبائیں، جو کوڈ (ghp_... سے شروع) ملے وہ یہاں پیسٹ کریں

جس کیٹگری کے پروڈکٹس بدلنے ہیں وہ منتخب کریں۔ ہر پروڈکٹ میں ایک یا زیادہ سائز/قیمت شامل کر سکتے ہیں۔
